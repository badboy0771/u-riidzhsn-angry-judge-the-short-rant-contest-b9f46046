# Unexpected Item

One short, funny rant about a small everyday annoyance — the self-checkout machine that accuses you of theft after you did all the work yourself.

> I scanned my own groceries, bagged my own groceries, paid for my own groceries — and the machine still froze and shouted UNEXPECTED ITEM like I'd smuggled in a second watermelon. I am not a thief. I am an unpaid cashier with a beeping supervisor.

It lands in three beats: the unpaid labour (scan, bag, pay), the accusation (UNEXPECTED ITEM, as if you smuggled a second watermelon), and the punchline that reframes the scene — you are not a thief, you are an unpaid cashier whose supervisor beeps. Specific, concrete, shared anger: everyone who has bagged their own groceries has lived this exact humiliation.

`main.ts` (Node 22, no dependencies, no network, deterministic) writes that single rant to `/output/entry.txt`, checks it is 1–400 characters, and reads it back to confirm the write.
